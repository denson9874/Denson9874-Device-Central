🧪 **Evolution X 12.3 for the Pixel 11 and Pixel 11 Pro: testers wanted**

The Pixel 11 Pro XL build now has two siblings: **Evolution X 12.3 (Android 17)** for the **Pixel 11 Pro (grizzly)** and the **Pixel 11 (cubs)**. Both are built from the same source with each phone's own stock images and blobs, and both pass every check I can run without the phones. But I don't own either one, so **neither has ever been booted**.

⚠️ **Before you flash**
• Use the zip for **your** phone only: grizzly = Pixel 11 Pro, cubs = Pixel 11
• Unlocked bootloader, and your phone's stock **CD1A.261005.003** already installed
• Clean install only, which wipes your data: `fastboot -w update <zip>`
• Only try it if you can restore stock with the Android Flash Tool if it doesn't boot

🙋 **If you try one**, please reply in its XDA thread: does it boot, your carrier, calls/SMS/VoLTE, mobile data, Wi-Fi, Bluetooth, cameras, fingerprint, face unlock, Play Integrity and Wallet. If something fails, a log helps a lot.
