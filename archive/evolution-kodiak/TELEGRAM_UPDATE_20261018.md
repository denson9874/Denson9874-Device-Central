🛠 **Evolution X for the Pixel 11 series: October 18 update**

New builds for the **Pixel 11 Pro XL (kodiak)**, **Pixel 11 Pro (grizzly)**, **Pixel 11 (cubs)** and **Pixel 11 Pro Fold (yogi)**, synced with this week's Evolution X source.

🔄 **Already on the October 16 build?** Settings > System > System updates has this one; it installs in the background, then restart. Rooted? Use Magisk > Install > *Install to inactive slot (after OTA)* instead of restarting, or root is gone.

What's new upstream:
• Google apps updated from Pixel 11 Pro firmware CD1A.261005.003
• Android System WebView 155.0.8059.39
• Evolver: spoofing settings redesigned in Material 3 Expressive
• Bluetooth no longer turns itself back on by default
• Mobile network: falls back to visible cells when a network scan is rejected
• Bug reports include the full kernel log
• Emergency information: picking a photo works without a crop app
• Translation updates across Evolution X and LineageOS apps

⚠️ **Known issue:** a user has reported that Now Playing won't turn on in this build. It's being looked into.

Unchanged: Espada kernel v3 (Linux 6.12.92) by Kevtrejo37 on kodiak, grizzly and cubs (yogi stays on stock Google GKI), Extreme Charging, the charging screensaver, "Use device MAC" for Wi-Fi networks that filter by MAC address (since the 10-16 build), and stock CD1A.261005.003 firmware (security patch 2026-10-05).
