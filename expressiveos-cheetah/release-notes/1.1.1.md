# ExpressiveOS {{VERSION}} for the {{MODEL}} — Golden Harvest

ExpressiveOS {{VERSION}} is a small security and stability update to 1.1. It tightens the checks on system features that regular apps should never reach, and fixes a handful of bugs found since 1.1.
On 1.1, it's a smaller update made just for your build: open the Updater and install it, and your apps and data stay. On 1.0, the Updater offers the full update, and your apps and data stay too. Coming from stock Android or another ROM, installing it wipes the phone, so back up first.

---

### ✨ What's New & Improved

#### 1. 🛡️ Security fixes
- **Before**: a few system features that ExpressiveOS inherited didn't check carefully enough which app was asking.
- **Now**: they answer only Android itself and the apps built into ExpressiveOS. App Lock, the private space, Game Space, freeform windows, the lock screen weather and the AirPods pop-up work as before. This update matters for every phone, so install it soon.

#### 2. 🔒 App Lock hides notifications right away
- **Before**: after you locked an app, its notifications could keep showing their content until SystemUI restarted.
- **Now**: a newly locked app's notifications are hidden as soon as you lock it.

#### 3. 🧭 Navigation bar styles work with Expressive Launcher
- **Before**: Studio's navigation bar styles listed only Default, or changed nothing, because they targeted a launcher that doesn't draw the bar.
- **Now**: the styles list and apply for the app that draws your navigation bar, Expressive Launcher or Pixel Launcher. If you had picked a style before, pick it again once after updating.

#### 4. 🔧 Fixes
- **Lock screen widgets** now follow Bluetooth, flashlight and ringer changes.
- **Pulse** with vibration on only vibrates while music plays, and stops when the music stops.
- **Gaming mode** no longer stays on when the phone restarts during a game.
- **Studio**: the battery bar's low battery colour applies, the wallpaper style options match the style you just picked, Dynamic Island's options show once, and Settings' wallpaper type screen opens its own page again.
- **The Updater** tells you when a new release is out, shows the new release's own notes (1.1 showed the installed build's), and refuses a local update made for a different phone.
- **Lock screen notifications** with blur on are prepared once instead of twice, so they show up faster.
- **Less background work**: SystemUI stops checking the battery time estimate every 2 minutes.

### 💬 Community Notes

- **Who it's for**: the {{MODEL}} ({{DEVICE}}) only. Install the build made for your exact phone.
- **Updating from 1.1 or 1.0**: open the Updater and install 1.1.1; your apps and data stay. If you added root yourself, an update replaces the boot images, so add it again afterwards.
- **Installing fresh**: ExpressiveOS's packages don't carry the bootloader or modem. Flash Google's latest Android 17 factory image for your phone first, then ExpressiveOS, with the web installer or fastboot.
