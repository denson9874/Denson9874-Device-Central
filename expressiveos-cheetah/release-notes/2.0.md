# ExpressiveOS {{VERSION}} for the {{MODEL}}

ExpressiveOS {{VERSION}} is rebuilt from the ground up directly on Android 17 AOSP, with Expressive Launcher 5.1.9, updated Wild Kernels root out of the box, and its own 2.0 update channel.
Because {{VERSION}} moves to a clean AOSP foundation, installing it from 1.x or stock Android requires a clean install that wipes the phone — back up your data first. Future 2.x updates install in place through the Updater as usual.

---

### ✨ What's New & Improved

#### 1. 🏗️ Built directly on Android 17 AOSP
- **Before**: earlier 1.x releases sat on top of an intermediate community base alongside AOSP.
- **Now**: ExpressiveOS {{VERSION}} is built straight on Android 17 AOSP, keeping Expressive Studio, the Updater, Expressive Launcher, ViPER4Android and Pixel hardware support while trimming everything else to a leaner base.

#### 2. 🚀 Expressive Launcher 5.1.9
- **Faster startup**: Expressive Launcher is now ahead-of-time compiled into native code during the build, cutting cold-start and gesture transition hitches.
- **Lower memory & battery use**: background graphics memory and idle wakeups on Adaptive refresh-rate screens are reduced.
- **Default Home & launcher switch**: Expressive Launcher is the default Home app out of the box with no setup prompt, and Expressive Studio's launcher switch lets you swap cleanly between Expressive Launcher and Pixel Launcher.
@yogi - **Foldable dock**: the inner display dock now keeps all five pinned icon slots aligned across fold and unfold transitions.

#### 3. 🔓 Root, out of the box (Wild Kernels r23)
@cheetah - Ships with Wild Kernels `6.1.172` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@husky - Ships with Wild Kernels `6.1.172` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@kodiak - Ships with Wild Kernels `6.12.92` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@grizzly - Ships with Wild Kernels `6.12.92` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@cubs - Ships with Wild Kernels `6.12.92` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@yogi - Ships with Wild Kernels `6.12.92` (BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
- Install the **Nightly** BakaSU manager APK from [https://github.com/Baka-SU/BakaSU/actions](https://github.com/Baka-SU/BakaSU/actions).
- **Don't want root?** Pick **Stock** in the web installer, or flash the matching `boot-stock.img` (`fastboot flash boot <that file>`).

#### 4. 🔊 Audio & Face Unlock refinements
@cheetah - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings and ships ViPER4Android out of the box.
@husky - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings, updated firmware support to `CP4A.261105.040.A1`, and ships ViPER4Android's AIDL driver.
@kodiak - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings and mounts ViPER4Android's AIDL driver earlier during boot so the audio HAL always sees it on first start.
@grizzly - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings and mounts ViPER4Android's AIDL driver earlier during boot so the audio HAL always sees it on first start.
@cubs - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings and mounts ViPER4Android's AIDL driver earlier during boot so the audio HAL always sees it on first start.
@yogi - **Face Unlock & ViPER4Android**: restored Pixel Face Unlock posture-guided enrollment in Settings, preserves enrollment state across fold/unfold, and mounts ViPER4Android's AIDL driver earlier during boot.
- **Silk Aurora boot animation**: pick the new **Silk Aurora** boot animation in **Settings → Expressive Studio → Themes → Boot animation**.
