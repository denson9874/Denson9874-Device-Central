# ExpressiveOS {{VERSION}} for the {{MODEL}} — Winter Camellia

ExpressiveOS {{VERSION}} is an in-place polish update for 1.3 with RCS messaging fixes, Expressive Launcher 5.1.9, updated Wild Kernels `r23` root out of the box, and reliability fixes across OTA updates, audio and contacts.
On 1.3 (or an earlier 1.x release), open **Settings → System → System updates** and install {{VERSION}} — your apps and data stay right where they are.

---

### ✨ What's New & Improved

#### 1. 💬 RCS messaging & Expressive Studio polish
- **RCS setup & carrier services**: fixed background registration issues in Google Messages and carrier IMS services so RCS chats connect reliably after setup or an update.
- **Expressive Studio**: importing an XML configuration file now opens straight to your **Downloads** folder and accepts both plain XML and Base64-encoded files, and Google Photos legacy device compatibility now defaults to off on fresh installs so native Pixel camera and backup features stay active out of the box.

#### 2. 🚀 Expressive Launcher 5.1.9
- **Ahead-of-time compiled**: Expressive Launcher is now compiled into native code during the build, making cold starts, app-drawer scrolling and Recents gesture transitions noticeably snappier right after boot.
- **Lower memory & idle drain**: reduced background graphics memory and idle wakeups on Adaptive refresh-rate screens.
- **Pixel Launcher mode switch**: fixed a boot-time property check so switching between Expressive Launcher and Pixel Launcher in Expressive Studio applies cleanly across reboots.
@yogi - **Foldable dock**: the inner display dock now keeps all five pinned icon slots aligned across fold and unfold transitions.

#### 3. 🔓 Updated Wild Kernels `r23`
@cheetah - Updated to Wild Kernels `r23` (`6.1.172` June 2026 GKI with BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.

@kodiak - Updated to Wild Kernels `r23` (`6.12.92` with BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.
@grizzly - Updated to Wild Kernels `r23` (`6.12.92` with BakaSU and susfs built in). Nothing gets root until you allow it in the BakaSU app.

#### 4. 🔧 Audio, OTA, Recovery & Contacts fixes
@kodiak - **ViPER4Android**: mounts the audio effect overlay earlier during boot (`post-fs`) so the Pixel audio HAL always detects ViPER4Android on its very first start.
@grizzly - **ViPER4Android**: mounts the audio effect overlay earlier during boot (`post-fs`) so the Pixel audio HAL always detects ViPER4Android on its very first start.

@kodiak - **Recovery & factory reset**: fixed SELinux rules in recovery and `fastbootd` so factory data resets complete cleanly on Pixel 11 hardware.
@grizzly - **Recovery & factory reset**: fixed SELinux rules in recovery and `fastbootd` so factory data resets complete cleanly on Pixel 11 hardware.

- **Post-OTA boot stability**: fixed two Virtual A/B snapshot merge bugs (`snapuserd` unaligned sector buffer sizing and `pkill -SIGNAL` argument parsing) that could interrupt background partition merges after an OTA reboot.
- **Custom contact ringtones**: assigning a custom ringtone to an individual contact in Google Contacts works again without crashing.
- **Face Unlock enrollment**: rotating or folding the screen during Face Unlock setup no longer opens a duplicate enrollment screen.
