### ✨ What's New & Improved

#### 1. 🛡️ The November 2026 security patch
- **Before**: 1.0 had the October 2026 security patch.
- **Now**: 1.1 brings LineageOS's November update, with security patch level `{{SPL}}`. It carries Google's November fixes for the framework, media, Bluetooth, Wi-Fi, NFC and telephony, plus small updates to LineageOS's own apps.
@cheetah - **Kernel**: the Android 6.1 kernel moves to Google's newer GKI release (android14-6.1 r25, from r24).
@husky - **Kernel**: the Android 6.1 kernel moves to Google's newer GKI release (android14-6.1 r25, from r24).

#### 2. 🎵 Now Playing recognizes songs again
- **Before**: Now Playing stayed on "Downloading song database", so it never recognized a song. The part of Android System Intelligence that fetches the database was cut off from the network.
- **Now**: the database downloads in the background, and Now Playing shows what's playing around you. The per-app network switch still works for every app.

#### 3. 📝 The Updater shows what's new
- **Before**: the Updater offered an update without its notes. Only What's new in Studio showed them.
- **Now**: the Updater shows these notes for the update it offers, before you install it.

#### 4. 📦 Smaller updates
- **Before**: every update was the whole system, a download of several gigabytes.
- **Now**: on 1.0, the Updater offers a smaller update made for exactly the build you're on, next to the full one. Each later release does the same for the build before it.

#### 5. 🏠 Expressive Launcher 5.1.1, built in
- **The 3-button navigation order switch works**: Android 17's switch that swaps back and recents now changes the bar, in portrait, landscape and on a foldable's big screen.
- **Small folders can be renamed again**: a Home folder with 4 apps or fewer shows its name, so you can tap it to rename the folder.
- **The drawer blurs properly** after you switch between full screen and bottom sheet, with no ghost of the drawer left on Home.
- **Smartspacer cards keep their first letters** on short At a Glance rows.

@kodiak #### 6. 🔧 Recovery and fastboot mode work
@kodiak - **Before**: on the Pixel 11 series, rebooting to recovery or to fastboot mode left the phone on the G logo, with nothing shown and nothing over USB. Anything that goes through recovery could hang the same way.
@kodiak - **Now**: recovery shows its menu, fastboot mode connects over USB within seconds, and both reboot back to Android as on stock.

### 💬 Community Notes

- **Who it's for**: the {{MODEL}} ({{DEVICE}}) only. Install the build made for your exact phone.
- **Updating from 1.0**: open the Updater and install 1.1; your apps and data stay. If you added root yourself, an update replaces the boot images, so add it again afterwards.
- **Installing fresh**: ExpressiveOS's packages don't carry the bootloader or modem. Flash Google's latest Android 17 factory image for your phone first, then ExpressiveOS, with the web installer or fastboot.
